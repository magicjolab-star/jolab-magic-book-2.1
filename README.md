# Jolab-Magic-Book-2.1

Application PWA d'évaluation d'échange pour véhicules récréatifs.

Cette version utilise une fonction serveur Vercel `/api/evaluate` et des variables d'environnement côté serveur. Aucune clé API ne doit être stockée dans le dépôt.
